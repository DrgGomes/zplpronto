DÚVIDAS FREQUENTES

O que você precisa saber

Funciona para etiquetas do Mercado Livre Full?

Esta versão suporta comandos ZPL comuns como texto, Code 128, posicionamento e quantidade (^PQ). Antes de usar no Full, confira o código impresso com um leitor e compare o SKU.

Meus arquivos são enviados para algum servidor?

Não. Nesta versão, os arquivos são lidos e convertidos diretamente no seu navegador, sem upload.

Posso imprimir direto na impressora térmica?

O botão Imprimir abre o diálogo de impressão do navegador. O navegador não tem autorização para imprimir silenciosamente em uma impressora específica. Escolha sua impressora, o papel correto e escala 100%.

O PDF mantém as dimensões?

Sim. Cada página usa a largura e a altura em milímetros escolhidas. A fidelidade dos comandos depende da cobertura do interpretador ZPL.
